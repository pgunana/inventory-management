Frontend Patterns

State Pattern

Raw API data stored in ref(). Derived/filtered values exposed as computed() properties. Computed properties are never mutated — changes emit up to parent.

Filter Singleton

useFilters() is a module-level singleton — refs live outside the function, so all views share the same filter state. Passing 'all' disables a filter.

Charts

Custom SVG — no charting library. All chart data transformations live in computed() properties. Components use CSS Grid for layout and Flexbox for arrangement.
